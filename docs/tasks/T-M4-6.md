# T-M4-6: セッション起動/終了通知

| 項目 | 内容 |
|------|------|
| マイルストーン | M4 |
| 依存 | T-M1-6 |
| 要件ID | FR-013 |

## 説明
セッションの起動・終了時に Discord にステータスメッセージを投稿する。

## 作業内容
1. セッション作成完了時の通知メッセージ（cwd, セッション名）
2. セッション正常終了時の通知メッセージ
3. セッション異常終了時の通知メッセージ（エラー情報付き）
4. Embed フォーマットでの表示

## タスクのチェックリスト
- [ ] セッション起動時にステータスメッセージが投稿される
- [ ] セッション終了時にステータスメッセージが投稿される
- [ ] 正常終了と異常終了が区別できる
