# T-M3-1: パーサーにツール許可・AskUser 検出パターンを追加

| 項目 | 内容 |
|------|------|
| マイルストーン | M3 |
| 依存 | T-M1-6 |
| 要件ID | FR-004 |

## 説明
`tmux/parser.ts` にツール許可待ち（"Do you want to proceed?"）と AskUserQuestion の検出パターンを追加する。

## 作業内容
1. 実機検証: ツール許可待ちの capture-pane 出力パターンを確認
2. 実機検証: AskUserQuestion の capture-pane 出力パターンを確認
3. `detectToolApproval(output)` -- ツール許可待ちパターン検出
4. `detectAskUser(output)` -- AskUserQuestion パターン検出
5. 正規化イベント層に `tool_approval` / `ask_user` イベントを追加
6. 選択肢の番号マッピング（Approve=1, AlwaysAllow=2, Deny=3 等）を確認

- [ ] AskUserQuestion パターンが正しく検出される

- [ ] 番号入力で選択肢を選べることが実機で確認済み
