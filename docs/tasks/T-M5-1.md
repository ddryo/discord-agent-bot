# T-M5-1: `/new` スラッシュコマンドの定義追加

| 項目 | 内容 |
|------|------|
| マイルストーン | M5 |
| 依存 | T-M2-1 |
| 要件ID | FR-019 |

## 説明
`commands.ts` に `/new` スラッシュコマンドを `SlashCommandBuilder` で定義する。

## 作業内容
1. `SlashCommandBuilder` で `/new` コマンドを定義
2. `title` オプション追加（String, required）-- スレッドタイトル（表示用）
3. `path` オプション追加（String, optional）-- セッションの cwd（省略時は DEFAULT_CWD）
4. `commands` 配列に追加し、`registerCommands` で Discord に登録されるようにする

## タスクのチェックリスト
- [ ] `/new` コマンドが `commands.ts` に定義されている
- [ ] `title` が必須の String オプションとして定義されている
- [ ] `path` が任意の String オプションとして定義されている
- [ ] `registerCommands` で他のコマンドと一緒に登録される
