## 説明
Claude CLI の出力を受け取り、Discord のメッセージとして投稿する `bot/responder.ts` を実装する。2000 文字制限の分割とコードブロックの整形を含む。

## 作業内容
1. OutputWatcher のイベントを受けて Discord チャンネル/スレッドに投稿
2. 2000 文字制限に基づくメッセージ分割
3. コードブロックが途中で切れないよう考慮した分割ロジック
4. Markdown 整形

## タスクのチェックリスト
- [x] Claude の応答が Discord に投稿される
- [x] 2000 文字超のメッセージが正しく分割される
- [x] コードブロックが途中で切断されない

## 実装結果メモ
- `sendToDiscord()` と `splitMessage()` の 2 関数構成
- 分割位置は改行を優先し、50% 以上前方に改行がない場合は 2000 文字で強制分割
- コードブロック補正: 奇数個のコードフェンスがある場合、閉じタグを付加し次チャンクに開きタグ（言語指定含む）を付加
