# T-M4-1: エラーハンドリング

| 項目 | 内容 |
|------|------|
| マイルストーン | M4 |
| 依存 | T-M2-3 |
| 要件ID | FR-014 |

## 説明
セッションの死亡検知や予期しないエラーのリカバリを実装する。

## 作業内容
1. tmux セッションの死亡検知（capture-pane 失敗 or hasSession が false）
2. セッション死亡時の Discord 通知
3. SessionStore のクリーンアップ
4. OutputWatcher の監視停止
5. 予期しないエラーの catch とログ出力
6. エラーからのリカバリ（Bot 全体のクラッシュ防止）

## タスクのチェックリスト
- [ ] セッションの異常終了が検知される
- [ ] 異常終了時に Discord に通知される
- [ ] エラー発生時に Bot がクラッシュしない
