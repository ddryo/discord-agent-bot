# T-M4-2: グレースフルシャットダウン

| 項目 | 内容 |
|------|------|
| マイルストーン | M4 |
| 依存 | T-M4-1 |
| 要件ID | FR-015 |

## 説明
SIGINT/SIGTERM 受信時に全 tmux セッションを終了し、リソースをクリーンアップしてから Bot を停止する。

## 作業内容
1. `process.on('SIGINT')` / `process.on('SIGTERM')` のハンドラ登録
2. 全セッションの OutputWatcher を停止
3. 全 tmux セッション（ccbot- プレフィックス）を killSession
4. Discord クライアントの切断
5. プロセス終了

## タスクのチェックリスト
- [ ] Ctrl+C で全 tmux セッションが終了する
- [ ] Bot プロセスが正常終了する
- [ ] リソースリークがない
