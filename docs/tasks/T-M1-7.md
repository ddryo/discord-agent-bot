# T-M1-7: 出力監視

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-5, T-M1-6 |
| 要件ID | FR-003 |

## 説明
セッションごとに出力を監視し、差分を検出してイベントを発火する `tmux/watcher.ts` を実装する。capture-pane ポーリングと pipe-pane + fs.watch の 2 方式を検証し、採用を決定する。

## 作業内容
1. OutputWatcher クラスを EventEmitter ベースで実装
2. `watch(sessionName)` -- ポーリング開始
3. `unwatch(sessionName)` -- ポーリング停止
4. 差分検出ロジック（前回キャプチャとの比較）
5. 検出した差分を parser に渡してイベント変換
6. イベント発火: "output", "idle", "session-end"
7. **検証**: pipe-pane 方式の実機テスト（採用可否を判断）

## タスクのチェックリスト
- [x] ポーリングで出力差分が検出される
- [x] 差分がイベントとして発火される
- [x] 複数セッションを同時に監視できる
- [x] pipe-pane 方式の検証結果が記録されている

## 実装結果メモ
- **採用方式**: capture-pane ポーリング方式を採用。pipe-pane 方式はファイル管理やバイナリ出力の扱いが煩雑なため不採用とした。
- **イベント設計**: EventEmitter で `"output"` イベントのみを発火し、イベント種別は `OutputEvent.type`（text / idle / session_end）で判定する設計。仕様の `"idle"`, `"session-end"` は独立イベントではなく OutputEvent の type で表現。
- **差分検出**: 前回キャプチャの末尾 5 行をマッチウィンドウとして今回の出力と照合し、一致位置以降を差分として抽出。マッチしない場合は全体を差分とみなす。
