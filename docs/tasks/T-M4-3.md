# T-M4-3: 起動時ヘルスチェック

| 項目 | 内容 |
|------|------|
| マイルストーン | M4 |
| 依存 | T-M1-5 |
| 要件ID | FR-016 |

## 説明
Bot 起動時に tmux と Claude CLI の存在を確認し、未インストールの場合に分かりやすいエラーメッセージを表示する。

## 作業内容
1. `tmux -V` で tmux の存在確認
2. `claude --version` で Claude CLI の存在確認
3. いずれかが存在しない場合にエラーメッセージを表示して終了
4. バージョン情報をログ出力

## タスクのチェックリスト
- [ ] tmux 未インストール時にエラーメッセージが出る
- [ ] Claude CLI 未インストール時にエラーメッセージが出る
- [ ] 正常時にバージョン情報がログ出力される
