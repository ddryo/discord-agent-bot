## 説明
Bun + TypeScript + discord.js の開発環境を構築し、プロジェクトの基盤を整える。

## 作業内容
1. `bun init` でプロジェクトを初期化
2. `discord.js` を依存に追加
3. `tsconfig.json` を strict モードで設定
4. `.env.example` を作成（必要な環境変数の一覧）
5. `.gitignore` を設定（node_modules, .env, dist 等）
6. エントリーポイント `src/index.ts` のスケルトンを作成
