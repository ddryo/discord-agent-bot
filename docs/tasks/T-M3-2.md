# T-M3-2: ツール許可通知・応答処理

| 項目 | 内容 |
|------|------|
| マイルストーン | M3 |
| 依存 | T-M3-1 |
| 要件ID | FR-008 |

## 説明
ツール実行許可待ちを Discord の Embed + ボタンで通知し、ユーザーの応答を Claude CLI に送信する `bot/interactions.ts` のツール許可部分を実装する。

## 作業内容
1. `sendToolApproval(target, info)` -- Embed + Approve / Always Allow / Deny ボタンの送信
2. `interactionCreate` イベントでボタン応答を受け取る
3. Approve --> send-keys で選択肢 1 を送信
4. Always Allow --> send-keys で選択肢 2 を送信
5. Deny --> send-keys で選択肢 3 を送信
6. 応答後にボタンを無効化（二重応答防止）

- [ ] 各ボタンの応答が正しく Claude CLI に送信される
- [ ] 応答後にボタンが無効化される
