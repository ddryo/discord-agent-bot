# T-M2-3: 複数セッションの並列ポーリング・動作検証

| 項目 | 内容 |
|------|------|
| マイルストーン | M2 |
| 依存 | T-M2-2 |
| 要件ID | FR-007 |

## 説明
複数のスレッドセッションが同時に稼働する状態で、各セッションの出力監視が正しく動作することを検証する。

## 作業内容
1. OutputWatcher が複数セッションを並列監視できるように確認・調整
2. 各セッションの出力が正しいスレッドに投稿されることを検証
3. セッション間の干渉がないことを確認
4. 負荷テスト（3-5 セッション同時稼働）

## タスクのチェックリスト
- [ ] 複数スレッドで同時に Claude と対話できる
- [ ] 各セッションの応答が正しいスレッドに投稿される
- [ ] セッション間で出力が混在しない
