# T-M1-8: Discord クライアント初期化

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-2 |
| 要件ID | なし |

## 説明
discord.js を使って Discord Bot クライアントを初期化し、必要な Intents とイベントリスナーを登録する `bot/client.ts` を実装する。

## 作業内容
1. Client インスタンスの作成（Intents: Guilds, GuildMessages, MessageContent）
2. `ready` イベントでログイン完了を通知
3. `messageCreate`, `interactionCreate` イベントの登録口を用意
4. Bot トークンでログイン

## タスクのチェックリスト
- [x] Bot がオンラインになる
- [x] ready イベントでログが出力される
- [x] messageCreate イベントが受信される

## 実装結果メモ
- `createDiscordClient()` ファクトリ関数で `DiscordClient` インターフェースを返す設計
- `onMessage()` / `onInteraction()` でハンドラを追加登録できる
- `interactionCreate` イベントの登録口も M3 に向けて用意済み
- Intents: `Guilds`, `GuildMessages`, `MessageContent`
