# T-M3-3: AskUserQuestion 通知・応答処理

| 項目 | 内容 |
|------|------|
| マイルストーン | M3 |
| 依存 | T-M3-1 |
| 要件ID | FR-009 |

## 説明
AskUserQuestion を Discord に通知し、選択肢ボタンまたはテキストメッセージでの応答を Claude CLI に送信する。

## 作業内容
1. `sendAskUser(target, info)` -- 質問テキスト + 選択肢ボタンの送信
2. ボタン応答 --> 選択肢番号を send-keys で送信
3. テキスト返答 --> メッセージ内容を send-keys で送信
4. AskUser 状態のセッションに対するメッセージをテキスト返答として処理
5. 応答後にボタンを無効化

## タスクのチェックリスト
- [ ] AskUserQuestion が質問 + ボタンで表示される
- [ ] ボタン応答が Claude CLI に送信される
- [ ] テキストメッセージでの返答が Claude CLI に送信される
