# T-M1-5: tmux セッション管理

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-2 |
| 要件ID | FR-002 |

## 説明
tmux コマンドをラップし、セッションのライフサイクル（作成・破棄・入出力）を管理する `tmux/manager.ts` を実装する。

## 実装方針

**セキュリティ**: tmux コマンドの実行には `Bun.spawn`（または `child_process.execFile`）の **引数配列形式** を使用し、シェル文字列結合は行わない。ユーザー入力（Discord メッセージ）を引数に渡す際もシェル解釈を経由させない。

## 作業内容
1. `createSession(name, cwd)` -- `Bun.spawn(["tmux", "new-session", "-d", "-s", name, "-c", cwd, "claude"])` でセッション作成
2. `killSession(name)` -- `Bun.spawn(["tmux", "kill-session", "-t", name])` でセッション破棄
3. `sendInput(name, text)` -- `Bun.spawn(["tmux", "send-keys", "-t", name, "-l", "--", text])` + `send-keys Enter` でテキスト入力
4. `sendKeys(name, keys)` -- 特殊キー送信（Escape, Up 等）
5. `capturePane(name, lines?)` -- `Bun.spawn(["tmux", "capture-pane", "-p", "-t", name, "-S", `-${lines}`])` で画面取得
6. `hasSession(name)` -- セッション存在確認
7. `listSessions()` -- ccbot- プレフィックスのセッション一覧
8. コマンド実行のエラーハンドリング

## タスクのチェックリスト
- [x] セッションの作成・破棄が正しく動作する
- [x] send-keys でテキストが入力される
- [x] capture-pane で出力が取得できる
- [x] 日本語テキストの send-keys が動作する
- [x] 存在しないセッションへの操作でエラーが適切に処理される

## 実装結果メモ
- 全コマンドで `Bun.spawn` の引数配列形式を使用（シェルインジェクション対策）
- セッション名は `ccbot-` プレフィックスを自動付与する内部関数 `runTmux()` で統一処理
- `killSession` は失敗時にも例外を投げずに warn ログで処理
