# T-M1-5: tmux セッション管理

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-2 |
| 要件ID | FR-002 |

## 説明
tmux コマンドをラップし、セッションのライフサイクル（作成・破棄・入出力）を管理する `tmux/manager.ts` を実装する。

## 作業内容
1. `createSession(name, cwd)` -- `tmux new-session -d -s {name} -c {cwd} "claude"` でセッション作成
2. `killSession(name)` -- `tmux kill-session -t {name}` でセッション破棄
3. `sendInput(name, text)` -- `tmux send-keys -t {name} -l -- "{text}"` + `send-keys Enter` でテキスト入力
4. `sendKeys(name, keys)` -- 特殊キー送信（Escape, Up 等）
5. `capturePane(name, lines?)` -- `tmux capture-pane -p -t {name} -S -{lines}` で画面取得
6. `hasSession(name)` -- セッション存在確認
7. `listSessions()` -- ccbot- プレフィックスのセッション一覧
8. コマンド実行のエラーハンドリング

## タスクのチェックリスト
- [ ] セッションの作成・破棄が正しく動作する
- [ ] send-keys でテキストが入力される
- [ ] capture-pane で出力が取得できる
- [ ] 日本語テキストの send-keys が動作する
- [ ] 存在しないセッションへの操作でエラーが適切に処理される
