# T-M1-9: メッセージ受信・振り分け

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-8, T-M1-5 |
| 要件ID | FR-001 |

## 説明
Discord のメッセージを受信し、対象チャンネルのフィルタリング・セッション振り分け・Claude CLI への入力送信を行う `bot/handler.ts` を実装する。

## 作業内容
1. 対象チャンネル（DISCORD_CHANNEL_ID）かどうかのフィルタリング
2. Bot 自身のメッセージを無視
3. メインチャンネルのメッセージ --> メインセッションに振り分け
4. セッションが未起動なら自動作成
5. `tmux/manager.ts` の `sendInput` でメッセージを Claude CLI に送信

## タスクのチェックリスト
- [ ] 対象チャンネル以外のメッセージが無視される
- [ ] Bot 自身のメッセージが無視される
- [ ] メッセージが Claude CLI に正しく送信される
- [ ] セッション未起動時に自動作成される
