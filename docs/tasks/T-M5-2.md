# T-M5-2: `/new` コマンドの処理実装

| 項目 | 内容 |
|------|------|
| マイルストーン | M5 |
| 依存 | T-M5-1 |
| 要件ID | FR-019 |

## 説明
`handler.ts` の `handleCommandInteraction` に `/new` コマンドの処理を実装する。スレッドを自動作成し、セッションを起動する。

## 作業内容
1. `handleCommandInteraction` に `commandName === "new"` の分岐を追加
2. `interaction.options.getString("title")` で必須の `title` を取得
3. `interaction.options.getString("path")` で任意の `path` を取得
4. `path` が指定されている場合:
   - `expandTilde` + `resolve` でパスを正規化
   - `BLOCKED_PATHS` に含まれていないかチェック（含まれていればエフェメラルエラー応答）
   - `stat` でディレクトリ存在確認（存在しない or ディレクトリでなければエフェメラルエラー応答）
5. `path` 未指定の場合: `config.defaultCwd` を使用
6. チャンネルの `threads.create()` でスレッドを作成（タイトル: `title`）
7. `ClaudeSessionInfo` を構築し、`sessionManager.registerSession()` でセッション登録
8. `sendSessionStartNotification()` で起動通知 Embed をスレッドに投稿
9. `interaction.reply()` でエフェメラル応答（「スレッドを作成しました」等）

## タスクのチェックリスト
- [ ] `/new` コマンドでスレッドが作成される
- [ ] `title` がスレッドタイトルに設定される
- [ ] `path` 指定時にそのパスが cwd になる
- [ ] `path` 省略時に DEFAULT_CWD が cwd になる
- [ ] `BLOCKED_PATHS` に該当するパスが拒否される
- [ ] 存在しないパスが拒否される
- [ ] セッションが SessionManager に登録される
- [ ] 起動通知 Embed がスレッドに投稿される
