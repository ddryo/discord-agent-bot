# T-M1-3: ログ出力モジュール

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-1 |
| 要件ID | なし |

## 説明
ログレベル付きのシンプルなロガーを実装する。

## 作業内容
1. ログレベル（debug, info, warn, error）を定義
2. タイムスタンプ付きのフォーマットで出力
3. セッション名などのコンテキスト情報を付与可能にする

## タスクのチェックリスト
- [x] 各ログレベルで出力できる
- [x] タイムスタンプが付与される

## 実装結果メモ
- `createLogger(context?)` でコンテキスト付きロガーを生成する設計
- ログレベルの動的切り替えは `setLogLevel()` で可能
- 出力フォーマット: `[YYYY-MM-DD HH:mm:ss] [LEVEL] [context] message`
