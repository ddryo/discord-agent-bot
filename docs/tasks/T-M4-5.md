# T-M4-5: 操作ユーザー制限の実装

| 項目 | 内容 |
|------|------|
| マイルストーン | M4 |
| 依存 | T-M1-9 |
| 要件ID | FR-017 |

## 説明
DISCORD_USER_ID が設定されている場合、そのユーザーのみ操作を許可する制限を実装する。

## 作業内容
1. handler.ts のメッセージ受信時にユーザー ID チェックを追加
2. interactions.ts のボタン応答時にユーザー ID チェックを追加
3. DISCORD_USER_ID 未設定時は全員許可
4. 許可されていないユーザーへのフィードバック

## タスクのチェックリスト
- [ ] 設定ユーザー以外のメッセージが無視される
- [ ] 設定ユーザー以外のボタン応答が拒否される
- [ ] DISCORD_USER_ID 未設定時は全員操作できる
