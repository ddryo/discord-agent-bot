## 説明
プロジェクト全体で共有する型定義を `types.ts` にまとめる。

## 作業内容
1. tmux セッション情報の型（TmuxSessionInfo: name, cwd, threadId 等）
2. パーサーイベント型（OutputEvent: text / tool_approval / ask_user / idle / session_end / error）
3. ツール許可情報の型（ToolApprovalInfo）
4. AskUser 情報の型（AskUserInfo）
5. 設定の型（Config）

## タスクのチェックリスト

## 実装結果メモ
- `SessionState` 型を追加定義: `"starting" | "ready" | "busy" | "dead"`
- `Config` 型は `types.ts` と `config.ts` の両方に存在する（`config.ts` 側は内部用のインターフェースとして定義）
