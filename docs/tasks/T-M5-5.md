# T-M5-5: 動作検証

| 項目 | 内容 |
|------|------|
| マイルストーン | M5 |
| 依存 | T-M5-4 |
| 要件ID | - |

## 説明
M5 の全タスク完了後に、手動スレッド作成・`/new` コマンド・パスバリデーションの動作を検証する。

## 作業内容
1. **手動スレッド作成テスト**
   - Discord UI からスレッドを作成し、DEFAULT_CWD でセッションが起動することを確認
   - スレッドタイトルに任意の文字列（パスでない文字列含む）を入力してもエラーにならないことを確認
2. **`/new` コマンドテスト（path 省略）**
   - `/new title:テスト` を実行し、スレッドが作成されて DEFAULT_CWD でセッションが起動することを確認
3. **`/new` コマンドテスト（path 指定）**
   - `/new title:テスト path:~/Desktop` を実行し、指定パスが cwd になることを確認
4. **パスバリデーションテスト**
   - `/new title:テスト path:/` で BLOCKED_PATHS エラーが返ることを確認
   - `/new title:テスト path:/nonexistent` で存在しないパスエラーが返ることを確認
5. **二重起動防止テスト**
   - `/new` 実行後に threadCreate イベントが発火しても、セッションが1つだけであることを確認

## タスクのチェックリスト
- [ ] 手動スレッド作成で DEFAULT_CWD セッションが起動する
- [ ] `/new` path 省略で DEFAULT_CWD セッションが起動する
- [ ] `/new` path 指定で指定パスのセッションが起動する
- [ ] BLOCKED_PATHS が正しく拒否される
- [ ] 存在しないパスが正しく拒否される
- [ ] 二重起動が発生しない
