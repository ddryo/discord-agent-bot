# T-M4-4: 長時間出力・大量出力への対策

| 項目 | 内容 |
|------|------|
| マイルストーン | M4 |
| 依存 | T-M1-10 |
| 要件ID | FR-018 |

## 説明
Claude CLI から長時間にわたる出力や大量のテキストが返された場合の対策を実装する。

## 作業内容
1. capture-pane のスクロールバック行数の調整（-S -500 等）
2. 大量テキストの分割投稿の安定化
3. コードブロック途中切断の回避ロジック強化
4. 連続投稿時の Discord rate limit 対策（必要に応じて遅延挿入）

## タスクのチェックリスト
- [ ] 長い応答が正しく分割投稿される
- [ ] コードブロックが途中で切れない
- [ ] rate limit エラーが発生しない（または適切にリトライされる）
