# T-M3-5: /exit コマンド対応

| 項目 | 内容 |
|------|------|
| マイルストーン | M3 |
| 依存 | T-M1-9 |
| 要件ID | FR-012 |

## 説明
`/exit` コマンドで tmux セッションを手動終了する機能を実装する。

## 作業内容
1. `/exit` コマンドの検出
2. 対応する tmux セッションを `killSession` で終了
3. SessionStore からセッション情報を削除
4. OutputWatcher の監視を停止
5. セッション終了メッセージを Discord に投稿

## タスクのチェックリスト
- [ ] /exit で tmux セッションが終了する
- [ ] SessionStore からセッション情報が削除される
- [ ] 監視が停止される
- [ ] 終了メッセージが投稿される
