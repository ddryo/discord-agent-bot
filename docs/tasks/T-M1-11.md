# T-M1-11: セッション状態管理（メインセッション）

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-5 |
| 要件ID | FR-005 |

## 説明
threadId と tmux セッションの対応関係を管理する `sessions/store.ts` を実装する。M1 ではメインセッションの管理のみ。

## 作業内容
1. SessionStore クラスの実装
2. メインセッション（ccbot-main）の登録・取得
3. `getSession(threadId)` -- threadId が null ならメインセッションを返す
4. `registerSession(threadId, info)` -- セッション情報を登録
5. `removeSession(threadId)` -- セッション情報を削除
6. `getAllSessions()` -- 全セッション一覧

## タスクのチェックリスト
- [x] メインセッションの登録・取得が正しく動作する
- [x] セッション情報の CRUD が機能する

## 実装結果メモ
- `SessionStore` クラスを `Map<string | null, TmuxSessionInfo>` で実装
- メインセッションの threadId は `null` で管理
- シングルトンインスタンス `sessionStore` を export
