# T-M1-2: 環境変数・設定モジュール

| 項目 | 内容 |
|------|------|

| 依存 | T-M1-1 |

## 説明
環境変数を読み込み、型付きの設定オブジェクトとして提供する `config.ts` を実装する。

## 作業内容
1. `.env` から環境変数を読み込む
2. 必須変数（DISCORD_BOT_TOKEN, DISCORD_CHANNEL_ID）のバリデーション
3. デフォルト値の適用（DEFAULT_CWD: `~/Desktop`, POLL_INTERVAL_MS: `1500`）
4. チルダ展開処理（`~/` を実際のホームディレクトリに変換）
5. 設定オブジェクトを export

## タスクのチェックリスト
- [x] 必須変数が未設定の場合にエラーメッセージが出る
- [x] デフォルト値が正しく適用される
- [x] チルダ展開が正しく動作する
