# T-M2-1: スレッド作成 --> 新規 tmux セッション起動

| 項目 | 内容 |
|------|------|
| マイルストーン | M2 |
| 依存 | T-M1-11 |
| 要件ID | FR-006 |

## 説明
Discord でスレッドが作成されたとき、スレッドタイトルを cwd パスとして解釈し、新規 tmux セッションを起動する。

## 作業内容
1. `threadCreate` イベントのハンドリング
2. 対象チャンネルの子スレッドかどうかの確認
3. スレッドタイトルをパスとして解釈（チルダ展開）
4. パスの存在チェック（存在しない場合はエラー通知）
5. `ccbot-{threadId}` の命名で新規 tmux セッション作成
6. SessionStore にスレッドセッションを登録
7. 起動完了メッセージをスレッドに投稿

## タスクのチェックリスト
- [ ] スレッド作成で tmux セッションが起動する
- [ ] スレッドタイトルのパスが cwd として設定される
- [ ] 存在しないパスの場合にエラーメッセージが投稿される
- [ ] セッション名が `ccbot-{threadId}` 形式になっている
