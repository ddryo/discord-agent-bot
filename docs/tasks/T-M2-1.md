# T-M2-1: スレッド作成 --> 新規 tmux セッション起動

| 項目 | 内容 |
|------|------|
| マイルストーン | M2 |
| 依存 | T-M1-11 |
| 要件ID | FR-006 |

## 説明
Discord でスレッドが作成されたとき、デフォルト cwd（`config.defaultCwd`）で新規 tmux セッションを起動する。スレッドタイトルは純粋に表示用であり、パスとして解釈しない。`/new` コマンド経由で既にセッションが登録済みの場合は二重起動を防止する。

## 作業内容
1. `threadCreate` イベントのハンドリング
2. 対象チャンネルの子スレッドかどうかの確認
3. `getSessionByThreadId` で既にセッション登録済みかチェック（`/new` 経由の二重起動防止）
4. `ccbot-{threadId}` の命名で新規 tmux セッション作成（cwd は常に `config.defaultCwd`）
5. SessionStore にスレッドセッションを登録
6. 起動完了メッセージをスレッドに投稿

## タスクのチェックリスト
- [x] スレッド作成で tmux セッションが起動する
- [x] cwd が常に DEFAULT_CWD で設定される
- [x] `/new` 経由で既にセッション登録済みの場合は二重起動しない
- [x] セッション名が `ccbot-{threadId}` 形式になっている
