# T-M1-6: 出力パーサー（基本パターン検出）

| 項目 | 内容 |
|------|------|
| マイルストーン | M1 |
| 依存 | T-M1-5 |
| 要件ID | FR-004 |

## 説明
tmux の出力テキストから ANSI エスケープシーケンスを除去し、基本的なパターン（アイドルプロンプト・セッション終了）を検出する `tmux/parser.ts` を実装する。ツール許可・AskUser の検出は M3 で追加する。

## 作業内容
1. `stripAnsi(text)` -- ANSI エスケープシーケンス除去
2. `detectIdlePrompt(output)` -- Claude CLI の入力待ちプロンプト検出
3. `detectSessionEnd(output)` -- セッション終了検出
4. raw テキスト --> OutputEvent への変換関数（正規化イベント層）
5. 実機検証: capture-pane の出力を確認し、検出パターンを確定させる

## タスクのチェックリスト
- [x] ANSI エスケープが正しく除去される
- [x] アイドルプロンプトが検出される
- [x] セッション終了が検出される
- [ ] 実機で capture-pane の出力パターンを確認済み

## 実装結果メモ
- ANSI 除去: SGR, CSI, OSC, 文字セット指定をカバーする正規表現で処理
- アイドルプロンプト検出: 末尾行が `>` やボックスドロー文字付きプロンプトにマッチするかで判定
- セッション終了検出: `session ended` / `goodbye` / `exiting` のキーワード、またはシェルプロンプト (`$`) の出現で判定
- `parseOutput()` は単一の `OutputEvent` を返す設計（M1 では text / idle / session_end のいずれか）
- ツール許可 (`tool_approval`) と AskUser (`ask_user`) の検出は M3 で追加予定
