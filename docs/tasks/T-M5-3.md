# T-M5-3: `handleThreadCreate` の簡略化

| 項目 | 内容 |
|------|------|
| マイルストーン | M5 |
| 依存 | T-M5-2 |
| 要件ID | FR-006 |

## 説明
`handleThreadCreate` からスレッドタイトルのパス解析ロジック（`expandTilde` + `resolve` + `stat`）を廃止し、常に `config.defaultCwd` でセッションを起動するように変更する。スレッドタイトルは純粋に表示用になる。

## 作業内容
1. `handleThreadCreate` から以下のロジックを削除:
   - `expandTilde(rawPath)` によるチルダ展開
   - `resolve(expandedPath)` によるパス正規化
   - `BLOCKED_PATHS.includes(candidatePath)` チェック
   - `stat(candidatePath)` によるディレクトリ存在確認
   - 無効パス時のフォールバックメッセージ送信
2. cwd を常に `config.defaultCwd` に設定
3. 不要になった import を整理（`stat`, `resolve`, `expandTilde` が handleThreadCreate 以外で使われていないなら削除）
4. ログメッセージの更新（パス解析に関する記述を表示用タイトルに変更）

## タスクのチェックリスト
- [ ] パス解析ロジック（expandTilde + resolve + stat）が handleThreadCreate から削除されている
- [ ] 手動スレッド作成時に常に DEFAULT_CWD でセッションが起動する
- [ ] スレッドタイトルに何を入力してもエラーにならない
- [ ] 不要な import が整理されている
