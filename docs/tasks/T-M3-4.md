# T-M3-4: CLI コマンド対応

| 項目 | 内容 |
|------|------|
| マイルストーン | M3 |
| 依存 | T-M1-9 |
| 要件ID | FR-010, FR-011 |

## 説明
Discord メッセージで `/` 始まりのコマンド（/clear, /compact, /cost, /context, /status, /model）を検出し、Claude CLI のスラッシュコマンドとして送信する。`/clear` は区切りメッセージを挿入する特別処理を行う。

## 作業内容
1. メッセージが `/` で始まるかどうかの判定
2. 対応コマンドリスト: `/clear`, `/compact`, `/cost`, `/context`, `/status`, `/model`
3. コマンドを send-keys で Claude CLI に送信
4. `/clear` の特別処理: CLI に送信後、Discord スレッドに区切り Embed を投稿
5. 未対応コマンドの場合はエラーメッセージ

## タスクのチェックリスト
- [ ] 対応する CLI コマンドが Claude CLI に送信される
- [ ] /clear で Discord に区切りメッセージが投稿される
- [ ] 未対応コマンドでエラーメッセージが出る
